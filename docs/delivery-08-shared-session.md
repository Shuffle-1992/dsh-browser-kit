## 1. 一句话结论

**共享批注会话模型落地**：同一 DSH 会话内多个浏览器窗口可参与同一份批注（编号跨窗口延续、
提交合并为单个协议文件、不同会话窗口互不影响）；正式入口三件套上线——**浏览器工具条批注图标
（每标签一个）+ 标签菜单「元素批注」项 + 页内批注面板**；左下角调试面板可最小化、正式版将门控隐藏。

## 2. 共享批注会话模型（用户需求逐条对照）

| 需求 | 实现 |
|---|---|
| 同会话 2 个窗口，备注共用 | 批注会话为 client 级共享状态：点任一窗口图标 = 该窗口「加入」；会话内其他窗口图标再点 = 也加入；提交时收集**全部成员面板**的批注，host `saveMerged` 按创建时间（element.capturedAt）权威重编号 1..N，构建单个协议文件 |
| 批注号跨窗口延续 | 编号下限（startIndex）在面板加入时交接：成员间最大已用号 + 1（窗口1 批了 1、2 → 窗口2 从 3 起）；页内徽标号 = 最终文件号，完全一致 |
| "备注3 跟备注1 尺寸一致" 可明确引用 | 协议文件按全局编号出 `## Annotation k`，徽标号一致 → 备注意见里写"跟备注1一致"即可精确定位 |
| 不同会话的窗口独立 | 成员制设计：未点图标的窗口不参与（跨会话归属的自动识别需宿主租约信息，列为后续增强） |

实现要点：批注层新增 `start({ startIndex })`（编号下限，向后兼容）；host `saveMerged(sets, meta)`
合并各组 → capturedAt 排序 → 权威重编号 → `src/annotations-protocol.js` 构建器（与页内逐字同源）
落盘 + index.jsonl（含 merged 组数）。

## 5. 本轮踩坑（P23 补充 + 新增观察）

1. **P23 补充**：guest-eval 重构时 `DOC || document` 在非 frame 路径引用未定义 DOC——重构引入的
   回归（cmd-99/101），修为按路径显式传 `document`；
2. **重构误删**：大会话块替换时连带删掉了 `ensureAnnotator` 定义（cmd-107 ReferenceError）——
   大块替换后必须全量 grep 调用点；
3. **整页注入 vs 活跃 SPA**：innerHTML 注入在 Vue 响应式刷新窗口会被重绘清空（cmd-78/79）——
   公网页面只做 snapshot/click/type；整页注入仅用于自有页面；
4. **僵尸实例**：toggle/HMR 多实例并存时命令被旧实例吞掉（cmd-102/105）——重发即可，刷新清场；
5. **startIndex 语义**：新会话首个成员 startIndex=0（首条=1 号）；后加入者 = 成员间最大号+1；
6. **批注内存跨会话保留**（契约）：重复提交会累积——提交/清场流程须 `clear()`。

## 8. 补充交付：跨面板同步引擎（用户实测反馈驱动，同日迭代）

用户双窗口实测反馈四项：①两窗口应显示同一板块；②计数徽标宽度；③展开/收起入口；④编号顺序。
全部落地，其中 ① 由新增的**同步引擎**实现：

- **gid 贯穿**：批注创建即分配全局唯一 gid（时间戳+随机），list()/协议外层均携带；
- **client 同步循环（1.5s，会话活跃时）**：收集各成员列表 → 以 gid 合并视图 → 缺失面板
  `addExternal` 推送（幂等：同 gid 只同步 note/index）→ 删除按 `union(各窗口删除日志)
  ∪ 来源面板消失` 全员移除；
- **批注层新 API**：`addExternal(items)`（按 gid 合并/更新，外部条目 el 按 selector best-effort
  解析、失败按 element.rect 定位灰徽标）、`removeExternal(gid)`、`__dshKitDeletedGids` 删除日志、
  `__dshKitAnnotatorVersion` 版本标记（client 检测不符自动重注入）；
- **实测证据**（panes-probe，2026-10-05 13:37）：tab0(keysion.cn) 与 tab1(5173) 各 **7 条、
  gid 序列完全一致**——窗口1 的批注实时出现在窗口2（含跨页条目的灰徽标定位）；
- **提交去重**：`saveMergedImpl` 按 gid 去重（同步后两面板持有相同集合，合并不产生重复），
  单测覆盖（40/40）。
